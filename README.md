# EPC Ventures – Company Website

A responsive single-page website for an energy-infrastructure EPC (engineering, procurement and construction) company.

## Features

- Single-page layout with sections for About, Services, Key Projects, Why Us, Clients, Vision and Contact
- "Request a Quote" form in a modal dialog (name, company, phone, email, service required)
- Animated number counters triggered on scroll (IntersectionObserver)
- Scroll-to-top button
- Responsive layout for mobile, tablet and desktop
- Full favicon set and web app manifest

## Tech stack

- HTML5
- Tailwind CSS (CDN)
- JavaScript (vanilla)
- Google Fonts

## How to run

No build step. Clone the repo and open `index.html` in a browser.
